# Preserve track photo originals without sharing them through track access

Track photos retain unchanged originals, but ordinary track access grants access
only to metadata-stripped display versions and captions. Originals can retain
location and other personal metadata, so making a track public must not publish
them; original downloads are restricted to the owner and administrators acting
through administration. This deliberately differs from the public GPX-original
download policy. Administrators can also edit photo captions and remove photos;
uploading and ordering photos remain owner operations.

This boundary was accepted during the photo-feature design interview on
2026-10-30. It describes planned behavior, not implemented functionality.
